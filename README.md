# Reva Kale — Portfolio

React + TypeScript + Vite portfolio for Reva Kale.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Resume

The portfolio expects the resume at:

`public/resume/RevaKale_Resume.pdf`

Replace that PDF whenever the resume is updated; the View Resume UI does not need code changes.
